# GENII wordmark assets

`source/genii-wordmark-original.png` is an untouched copy of the authoritative
source supplied for the website. Its SHA-256 checksum is:

`87e670aff0107c61deb0aa3f0d9d8f4a2b0f72aa917ae124aa684d6247b13202`

The black web derivative in `public/brand` preserves the exact source glyph
geometry, proportions, and spacing. It removes the photographed white field
without redrawing, typesetting, or reconstructing the mark.

The application icons use an exact crop of the source G glyph. The original
source must remain unchanged.
